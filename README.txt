SELAM'S BIRTHDAY WEBSITE

Files:
- index.html: the website
- images/: the six supplied photos
- music.mp3: add a music file here if you have a legally obtained copy and permission to use it

IMPORTANT MUSIC NOTE:
The page is set up to play a local file named music.mp3 after Selam taps the music button.
Please add the chosen Amharic song as music.mp3 only if you have a copy you are allowed to use. The website does not include copyrighted music.

PUBLISH WITH GITHUB PAGES:
1. Create a new GitHub repository.
2. Upload index.html, the images folder, and music.mp3 (if you have it).
3. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
4. Open the published Pages address.

The website uses Google Fonts for a polished Amharic typeface when internet is available; it has fallback fonts too.
